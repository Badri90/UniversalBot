# Бот учёта абонементов борцовского зала

Telegram-бот на Python: учёт абонементов клиентов, напоминания об истечении срока
и запись на тренировки.

## Что умеет

**Клиенты:**
- `/start` — регистрация в системе
- `/my` — статус своего абонемента (срок действия / оставшиеся посещения)
- `/trainings` — список ближайших тренировок
- `/book <номер>` — записаться на тренировку
- `/cancel <номер>` — отменить запись
- `/mybookings` — список своих записей

**Администратор (тренер/владелец зала):**
- `/add_client <telegram_id> <ФИО>` — добавить клиента вручную
- `/add_sub <telegram_id> "Название" <дней> [посещений]` — выдать абонемент
- `/clients` — список всех клиентов
- `/add_training ДД.ММ.ГГГГ ЧЧ:ММ "Название" [макс_участников]` — создать тренировку
- `/trainings_all` — все тренировки с числом записавшихся

Каждый день в 10:00 бот сам разошлёт клиентам напоминание, если их абонемент
истекает в течение ближайших 3 дней.

## Установка

1. Установите Python 3.10+.
2. Создайте бота через [@BotFather](https://t.me/BotFather) в Telegram и получите токен.
3. Узнайте свой telegram_id (например, через [@userinfobot](https://t.me/userinfobot)) —
   он понадобится, чтобы дать себе права администратора.
4. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
5. Скопируйте `.env.example` в `.env` и заполните:
   ```
   BOT_TOKEN=токен_от_BotFather
   ADMIN_IDS=ваш_telegram_id
   ```
   Если админов несколько — перечислите через запятую.
6. Запустите бота:
   ```bash
   python bot.py
   ```

При первом запуске автоматически создастся файл базы данных `gym.db`
(SQLite) — в нём хранятся все клиенты, абонементы, тренировки и записи.
Отдельная СУБД не нужна.

## Пример работы администратора

```
/add_client 111222333 Иванов Иван
/add_sub 111222333 "Месячный безлимит" 30
/add_sub 111222333 "10 занятий" 60 10
/add_training 20.09.2026 18:00 "Вечерняя группа" 15
```

## Важно про хостинг

Бот должен работать постоянно (24/7), чтобы клиенты могли писать ему
и чтобы срабатывали напоминания. Для этого его нужно разместить на
сервере — подойдёт даже самый простой VPS (от ~150–300 руб/мес) или
бесплатные варианты вроде PythonAnywhere / Railway на старте. Локально
на своём компьютере бот будет работать, только пока запущен скрипт.
