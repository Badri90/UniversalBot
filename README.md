# Бот учёта абонементов борцовского зала — Universal Jiu-Jitsu Batumi

Telegram-бот с мини-аппом (личный кабинет + панель тренера): учёт абонементов,
напоминания об оплате, заморозка и активация абонемента.

## Что умеет

**Клиенты:**
- `/start` — единственная команда. Открывает мини-апп (личный кабинет), где
  происходит вся остальная работа: регистрация, статус абонемента, заморозка,
  активация. Прочие текстовые команды для клиентов отключены.

**Администратор (тренер/владелец зала):**
- `/admin_app` — панель тренера (клиенты, заморозки, активация, объявление)
- `/clients` — список всех клиентов с номерами (1, 2, 3...)
- `/add_sub <номер_клиента> "Название" ДД.ММ.ГГГГ [месяцев] [посещений]` — записать оплату
- `/due` — кто должен оплатить в ближайшие 5 дней или уже просрочил
- `/add_client <telegram_id> <ФИО>` — добавить клиента вручную (редко нужно, см. ниже)
- `/add_training ДД.ММ.ГГГГ ЧЧ:ММ "Название" [макс_участников]` — создать тренировку
- `/trainings_all` — все тренировки с числом записавшихся
- `/backup` / `/restore` — резервное копирование базы данных

### Как добавлять клиентов (без танцев с telegram_id)

Клиенту не нужно ничего вам сообщать — достаточно, чтобы он **один раз написал
боту `/start`** и зарегистрировался в открывшемся мини-аппе (выбрав группу
Adult/Kids, указав имя и дату рождения). После этого откройте `/clients` —
увидите список вида:

```
1: Иванов Иван (tg:987654321)
2: Петрова Мария (tg:555444333)
```

Число в начале строки (1, 2...) — это и есть тот самый простой номер, который
вы используете во всех дальнейших командах, никакой telegram_id запоминать
не нужно.

Команда `/add_client` нужна только в редком случае — если хотите завести
клиента в базе заранее, до того как он написал боту (например, чтобы сразу
выдать абонемент). Тогда telegram_id всё же понадобится — его клиент может
узнать через @userinfobot.

### Как считается оплата

Вы указываете **дату, когда клиент заплатил**, а бот сам считает дату следующей
оплаты — та же дата через N месяцев (по умолчанию 1 месяц). Например:

```
/add_sub 1 "Абонемент" 05.10.2026
```

Следующая оплата будет автоматически **05.11.2026** — не "через 30 дней",
а именно то же число следующего месяца. Если хотите указать другой период
(например абонемент на 3 месяца), добавьте число месяцев:

```
/add_sub 1 "Квартальный" 05.10.2026 3
```

→ следующая оплата 05.01.2027.

Каждый день в 10:00 бот сам присылает клиенту напоминание, если до даты
оплаты осталось 3 дня или меньше. Вам как админу не нужно за этим следить
вручную — но если хотите увидеть картину целиком, в любой момент напишите
боту `/due`: он покажет и тех, у кого оплата скоро, и тех, кто уже просрочил.

## Личный кабинет (Telegram Mini App)

Регистрация и вся работа клиента происходит **внутри мини-аппа**, а не через
текстовые команды бота — у клиентов работает только команда `/start` (она же
открывает кабинет), все остальные текстовые команды для них отключены.
Рядом с полем ввода сообщения в боте (кнопка меню, слева от скрепки) есть
постоянная кнопка **«Открыть кабинет»**.

- **Клиент**: открывает кабинет → если не зарегистрирован, видит форму:
  выбор группы (Adult/Kids), имя и фамилия, дата рождения → после отправки
  видит: свой **пояс** (нарисован как настоящий пояс BJJ с чёрной нашивкой
  и полосками), статус абонемента, **календарь посещений** с листанием по
  месяцам, и **расписание** своей группы с подсветкой сегодняшнего дня. Если абонемента нет — кнопка
  «Активировать абонемент», если есть — «Заморозить абонемент». Внизу —
  ссылки на Instagram и Telegram-чат команды. Сверху — переключатель RU / EN.
- **Тренер**: команда `/admin_app` → вкладки:
  - **Клиенты** — список свёрнутых карточек (имя, фамилия, дата окончания
    абонемента). Разворачивается по нажатию: группа, дата рождения, пояс,
    статус, кнопки «Отметить оплату» (с суммой — она идёт в статистику),
    «Изменить имя», «Пояс», «Открыть кабинет клиента» (показывает страницу
    глазами клиента), «Удалить», и поле **личной заметки** (видна только вам). Фильтры по группе и по сроку абонемента, поиск, сортировка.
  - **Посещения** — выбираете дату, отмечаете пришедших одним нажатием.
    Рядом с каждым видно, сколько раз он был в этом месяце.
  - **Расписание** — занятия по дням недели, редактируются в реальном
    времени: клиенты видят изменения сразу при следующем открытии кабинета.
    У занятия можно указать группу (Все / Adult / Kids) — клиент видит
    только своё.
  - **Статистика** — доход за месяц, число оплат, активные абонементы,
    клиенты без абонемента, новые за месяц, посещения, разбивка Adult/Kids.
    Месяцы листаются стрелками.
  - **Заморозки** — заявки на паузу абонемента.
  - **Активация** — заявки на старт абонемента; дату можно поправить.
  - **Объявление** — текст, который увидят все клиенты в кабинете.

### Напоминания об оплате

Бот сам пишет клиенту: за 3 дня до истечения абонемента, в день истечения,
и затем **каждый день**, пока клиент не получит новый оплаченный абонемент.
Работает автоматически, раз в сутки, вмешательство не требуется.

### Обязательные переменные окружения на Railway

```
BOT_TOKEN=токен_от_BotFather
ADMIN_IDS=ваш_telegram_id
WEBAPP_URL=https://ваш-домен.up.railway.app
DB_PATH=/data/gym.db
TZ=Asia/Tbilisi
```

`TZ` важна: Railway по умолчанию работает по UTC, и без этой переменной
напоминания уходили бы на 4 часа позже, а «сегодня» при активации абонемента
могло определяться неверно.

Необязательные:
- `SUBSCRIPTION_PRICE` — стоимость абонемента (по умолчанию 130).
- `REMINDER_HOUR` — час рассылки напоминаний (по умолчанию 10).
- `REMINDER_MAX_DAYS_OVERDUE` — сколько дней после истечения продолжать
  ежедневные напоминания (по умолчанию 14). Поставьте `0`, чтобы напоминать
  бессрочно — но тогда клиент, который ушёл из зала, будет получать
  сообщение каждый день без конца.

### Как включить мини-апп на Railway

1. В настройках сервиса на Railway откройте **Settings → Networking** и
   нажмите **Generate Domain** — Railway выдаст публичный адрес вида
   `https://your-bot.up.railway.app`.
2. Добавьте новую переменную в **Variables**:
   ```
   WEBAPP_URL=https://your-bot.up.railway.app
   ```
   (без `/` на конце)
3. Передеплойте сервис — после этого команды `/app` и `/admin_app` в боте
   покажут кнопку для открытия кабинета.

Без переменной `WEBAPP_URL` бот продолжит работать как раньше, просто без
кнопки кабинета.

## ⚠️ Обязательно: постоянное хранилище данных

По умолчанию база данных (`gym.db`) хранится прямо в контейнере Railway.
**При каждом передеплое (когда вы обновляете файлы на GitHub) этот файл
удаляется вместе со всеми клиентами, оплатами и заявками.** Это нужно
исправить один раз, до того как в базе появятся реальные люди.

### Как подключить постоянный диск (Volume) на Railway

1. Откройте ваш сервис на Railway → вкладка **Settings** → раздел **Volumes**
   → **+ New Volume**.
2. В качестве Mount Path укажите: `/data`
3. В **Variables** добавьте новую переменную:
   ```
   DB_PATH=/data/gym.db
   ```
4. Передеплойте сервис.

После этого база будет жить на отдельном постоянном диске и не будет
затрагиваться обновлениями кода. Если вы уже успели ввести реальные данные
без Volume — придётся один раз занести их заново после подключения диска
(например, командами `/add_sub`, либо через регистрацию клиентов заново).

### Резервное копирование

Дополнительная подстраховка на случай проблем с самим Railway:

- `/backup` — бот присылает вам файл базы данных (`gym.db`) прямо в чат.
  Скачайте и держите где-то у себя (например, перешлите в "Избранное").
- Чтобы восстановить данные из бэкапа: **ответьте на сообщение с файлом**
  командой `/restore`. Бот проверит, что файл — рабочая база данных, и
  только после этого заменит текущую базу.

⚠️ `/restore` заменяет данные **для всех** — и в вашей админ-панели, и в
личных кабинетах всех клиентов, так как база одна общая. Команда доступна
только админу.

## Установка

1. Установите Python 3.10+.
2. Создайте бота через [@BotFather](https://t.me/BotFather) в Telegram и получите токен.
3. Узнайте свой telegram_id (например, через [@userinfobot](https://t.me/userinfobot)) —
   он понадобится, чтобы дать себе права администратора.
4. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
5. Скопируйте `.env.example` в `.env` и заполните:
   ```
   BOT_TOKEN=токен_от_BotFather
   ADMIN_IDS=ваш_telegram_id
   ```
   Если админов несколько — перечислите через запятую.
6. Запустите бота:
   ```bash
   python bot.py
   ```

При первом запуске автоматически создастся файл базы данных `gym.db`
(SQLite) — в нём хранятся все клиенты, абонементы, тренировки и записи.
Отдельная СУБД не нужна.


## Важно про хостинг

Бот должен работать постоянно (24/7), чтобы клиенты могли писать ему
и чтобы срабатывали напоминания. Для этого его нужно разместить на
сервере — подойдёт даже самый простой VPS (от ~150–300 руб/мес) или
бесплатные варианты вроде PythonAnywhere / Railway на старте. Локально
на своём компьютере бот будет работать, только пока запущен скрипт.
